# 📊 Sales Performance Dashboard

An Excel-based sales analytics dashboard built using Pivot Tables, Charts, and KPI tracking across 5 regions and 5 product categories for FY 2023.

---

## 📌 What This Project Does

Takes 300 rows of raw sales data and turns it into a clean, manager-ready dashboard that answers:

- Which region is generating the most revenue?
- Which product category is most profitable?
- How are sales trending month over month?
- Where should the sales team focus next quarter?

---

## 📂 What's Inside the Excel File

| Sheet | What it shows |

| Category Analysis | Pivot table + pie chart by category |

| Raw Data | Full 300-row dataset |

## 📁 Dataset

**300 rows — 12 months × 5 regions × 5 categories**

| Column | Description |
|---|---|
| Month | Jan 2023 – Dec 2023 |
| Region | North, South, East, West, Central |
| Category | Electronics, Clothing, Furniture, Groceries, Sports |
| Sales | Gross revenue in ₹ |
| Units_Sold | Number of units sold |
| Profit | Net profit in ₹ |
| Profit_Margin_% | Profit ÷ Sales × 100 |

## 💡 Business Insights

1. **North has the highest profit margin (23.6%)** — most efficient region despite ranking 3rd in revenue
2. **Electronics has high margin but lowest sales** — opportunity to scale volume
3. **Furniture has the lowest margin (20.8%)** — pricing needs review
4. **Mid-year slump (June–August)** across all regions — seasonal promotions recommended
5. **West leads in Groceries** — targeted promotions here can push overall revenue
